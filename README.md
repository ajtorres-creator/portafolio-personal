# Portafolio Personal

## Nombre del estudiante

Anthony Torres

## Descripción

Este proyecto corresponde a mi portafolio personal desarrollado como parte de mi formación académica, el sitio presenta información sobre mí.
El objetivo del portafolio es mostrar los conocimientos que estoy adquiriendo en el desarrollo de páginas web 
## Tecnologías utilizadas

- HTML
- CSS
- Git
- GitHub

## Estructura del proyecto

El proyecto está organizado de la siguiente manera:

- `index.html` - Página principal del portafolio.
- `styles.css` - Archivo utilizado para los estilos y diseño.
- `img/` - Carpeta que contiene las imágenes utilizadas en el sitio.
- `README.md` - Documentación del proyecto.

## Cómo visualizar el proyecto

Para visualizar el portafolio, se puede descargar o clonar el repositorio y abrir el archivo `index.html` en un navegador web.

También puede visualizarse mediante GitHub
