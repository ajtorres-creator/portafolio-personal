# Portafolio Personal

Estudiante: Anthony Torres

## Descripción

Este proyecto corresponde a mi portafolio personal, desarrollado como parte de mi formación académica.

En esta segunda versión se incorporaron funcionalidades interactivas utilizando JavaScript, manteniendo la estructura original desarrollada con HTML y CSS.

## Funcionalidades

El portafolio cuenta con las siguientes funcionalidades:

- Navegación entre las diferentes secciones.
- Eventos interactivos mediante `addEventListener()`.
- Cambio dinámico de mensajes mediante JavaScript.
- Validación básica del formulario de contacto.
- Modo oscuro y modo claro.
- Almacenamiento de la preferencia de tema mediante `localStorage`.
- Recuperación de la preferencia guardada al recargar la página.
